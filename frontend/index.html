Trendar

빠르게 성장하는 GitHub 프로젝트를 남들보다 먼저.

Trendar는 관심 주제와 관련된 오픈소스를 6시간마다 확인해 최근 스타가 빠르게 늘어난 프로젝트를 찾아줍니다. 시간에 따른 스타 수 변화를 기록하므로 지금 성장 중인지 쉽게 비교할 수 있습니다.

  • 최근 스타가 빠르게 늘어난 프로젝트 순위
  • 신생 프로젝트의 최근 24시간 성장 순위
  • 관심 주제별 자동 수집과 스타 변화 차트
  • 사용 언어 분포, 관심 프로젝트 저장과 메모
