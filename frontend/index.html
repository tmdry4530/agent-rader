Trendar

지금 뜨는 GitHub 레포를 남들보다 먼저.

Trendar는 관심 키워드의 오픈소스를 6시간마다 추적해 스타 증가율(추세)로 급상승 레포를 골라주는 GitHub 트렌드 레이더입니다. GitHub이 알려주지 않는 “지금 뜨고 있는지”를 시점별 스냅샷의 델타로 계산합니다.

  • 스타 증가율 기반 급상승 레포 랭킹
  • 신생 레포 속도(스타/경과일) 랭킹 — 역대 상위에 가려진 신규 프로젝트 발견
  • 관심 키워드(watch query)만 선별 수집, 시계열 성장 추이 차트
  • 언어·조건별 생태계 분포, 북마크·메모 큐레이션

가입 없이 GitHub 계정으로 로그인 · 공개 정보만 사용 · 무료
